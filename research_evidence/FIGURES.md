Each entry links the figure to its research question, experiment, metric,
seed count, interpretation, source data, and relevant report/statistics
file. This is generated by reading `manifest.json` and the per-figure
`.json` metadata sidecars next to each PNG — it does not introduce any
value not already present there. Run `genevra verify-evidence` to confirm
every reference below still resolves and every checksum still matches.

## Regenerating

- All figures except `research_question_summary.png` are produced by
  `genevra.evidence.build.build_evidence_package` (invoked via
  `genevra reproduce-evidence`), which re-runs the underlying experiments.
- `research_question_summary.png` is produced by
  [`scripts/generate_research_question_summary_figure.py`](../scripts/generate_research_question_summary_figure.py),
  which reads only `tables/research_question_matrix.csv` — it does not run
  any simulation and can be safely re-run whenever that table changes.

See [`docs/research_evidence_gallery.md`](../docs/research_evidence_gallery.md)
for the paper-style presentation of these figures with full captions.
