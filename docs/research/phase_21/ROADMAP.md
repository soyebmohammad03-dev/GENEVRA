# Finite research roadmap

1. **External artifact review.** Send the public replay package and reviewer guide to an independent statistical reviewer when authorized. Require their own environment, calculations, discrepancy report and scope judgment. Local independent implementation checks and outside review are separate.
2. **Partner feasibility.** Identify one monitoring partner and a separately governed frame and reference lab. Price the incremental coverage evidence and holdout acquisition. Register a single operational outcome and thresholds. If off-roster reach and reference precision cannot be established, end this track.
3. **Bounded feasibility pilot.** Use the proposed 12 episodes after operational preregistration. This can falsify access, adjudication and cost assumptions. It cannot pass the confirmatory risk gate.
4. **Submission decision.** Require evidence that the benchmark contributes actionable information beyond known partial identification. If a powered external study is impractical or yields no useful insight, keep a technical artifact and avoid a superiority or methods submission. Biological validity requires a separate endpoint bridge and independent biological reference program.

Do not add another synthetic phase merely to enlarge the benchmark. Prioritize valid target access, outcome precision and actual costs.
