# GENEVRA JSS preparation package

This candidate package reformats the [corrected Phase 29 manuscript](../rendered/manuscript.pdf) for the Journal of Statistical Software. The frozen benchmark, evidence, and technical review copy remain the scientific source. See the [Phase 29 record](../README.md) for the research scope and decision.

| Material | Location |
|---|---|
| JSS draft | [PDF](manuscript.pdf), [LaTeX](manuscript.tex), [BibTeX](references.bib) |
| Publication inputs | [Figures](../../phase_28/rendered/figures), [tables](../../phase_28/rendered/tables), [evidence receipt](../rendered/audit-receipt.json) |
| Replication | [Software guide](SOFTWARE_GUIDE.md), [supplement](../SUPPLEMENT.md), [claim-to-evidence map](../CLAIM_TO_EVIDENCE.md), [frozen archive record](../../archive.json) |
| Journal checks | [Compliance matrix](COMPLIANCE.md), [software comparison](COMPARISON.md), [cover letter draft](COVER_LETTER.md), [author checklist](AUTHOR_CHECKLIST.md) |
| Integrity | [Preparation checksums](SHA256SUMS), [frozen Phase 29 inputs](../FROZEN_SHA256SUMS), [verification record](VERIFICATION.md) |

The manuscript build copies the five frozen figure files and obtains the pinned official JSS class and bibliography style. Follow the software guide to assemble the source directory and to replay the archived benchmark. The package is for internal review. Portal acceptance, independent reproduction, and software usefulness remain open.
