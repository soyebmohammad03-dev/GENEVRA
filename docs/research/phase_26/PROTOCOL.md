# GENEVRA Phase 26 audit protocol

Recreate the frozen Phase 25 records in a new directory and verify their published digest. Independently check all paid allocations, per-stratum counts and widths, endpoint classifications, paired effects and uncertainty. Keep the Phase 25 primary and secondary estimands unchanged.

The separate exploratory sweep uses 96 replicates for each of 23 named scenarios. Its reference is the Phase 25 primary law and its own seed. Change one conceptual factor at a time using the values in the [audit design](design.json). The large-omission and no-omission interventions jointly change the mass and the reported cap. Incorrect weights change the assumed weights of every inference and allocation method while holding true mixture weights fixed. Pilot distortion multiplies and rounds the high-stratum count presented to all policies, with valid count bounds. This perturbs the input to the plug-in variance formula. It does not model a particular field measurement error. Nominal coverage changes the interval alpha, rather than conditioning on realized coverage. No tuning, reruns with changed seeds, or outcome-based exclusions.

Use common uniform prefixes across arms and scenarios with separate pilot and inference seed namespaces. Charge the same pilot and exact acquisition budget within each scenario. Keep the Phase 25 methods and decision thresholds except where the design explicitly changes an input. Oracle rates remain privileged. Use a nominal independent-replicate paired Hoeffding interval for the primary historical contrast and Bonferroni for its historical secondary family. Report exploratory sweep counts and contrasts descriptively, with no significance or generalized superiority claims. The experiment tests responses to named synthetic interventions. It cannot identify causal mechanisms outside the model or rank methods across untested interactions.
