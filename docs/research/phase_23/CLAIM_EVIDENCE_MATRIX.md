# Claim-evidence matrix

Each row has one status. **1** directly established by reproducible results. **2** supported only under specified synthetic assumptions. **3** supported by external descriptive evidence. **4** proposed but untested. **5** unsupported or withdrawn. Status 1 for a computation establishes its result under the declared inputs, without establishing that the inputs describe a real population.
