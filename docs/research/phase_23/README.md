# GENEVRA Phase 23 external review package

**Status.** Open for external scrutiny. Journal submission and field recruitment remain on hold. The three reviews here are internally generated simulations. No external reviewer or partner has participated.

GENEVRA began with a digital-organism question about whether evolvability can be inherited and selected under environmental change. Unstable beneficial-fraction measurements and unresolved reference labels redirected the work toward measurement validity. The resulting benchmark asks when limited access permits a precise paired-score estimate or an anchor certificate, and what happens when calibration and evaluation omit the same units.

## Questions for external adjudication

- Does the identification argument cover all plausible ways that a reference frame can miss eligible units? Give a counterexample or state the precise assumptions under which it holds.
- Do the comparators share all information relevant to the contrast? Which strong comparator is missing, and would it change the interpretation of the negative result?
- Can you reproduce both the failures and the recoveries from the archive? Return source and input hashes, versions, commands, deviations, numerical discrepancies and any independence limitations.
- What prior benchmark most directly overlaps the claimed contribution? Identify the incremental scientific value, if any.
- Could an independently administered frame and reference assay support the field estimand? What exclusions or operational restrictions would change it?
