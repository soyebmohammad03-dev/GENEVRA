# JSS submission checklist

| Requirement | Verdict | Evidence or next action |
|---|---|---|
| JSS-style English LaTeX manuscript and PDF | COMPLETE for the review candidate | Official class and bibliography style, 11 rendered pages, all displays and citations checked. The draft retains the review layout and pending affiliation. |
| Human-readable ASCII software source, installability and formatted help | COMPLETE for the candidate software | The separately prepared ASCII source, wheel and help passed the [closure verification](../JSS_SOURCE_COMPLIANCE_FINAL.md). The editorial task leaves software unchanged. |
| Original work, compatible software license and attachment permissions | AUTHOR ACTION REQUIRED | MIT source is documented. Confirm authorship, originality, submission disclosures and rights for the final figures, archive and any third-party materials. |
| Replication material and exact output on a disclosed platform | COMPLETE with documented platform scope | The published macOS arm64 replay has been internally verified. The editorial build reproduces the revised presentation from that evidence without rerunning the benchmark. The [external reproduction guide](../EXTERNAL_REPRODUCTION_GUIDE.md) retains the original replay and receipt. |
| Historical replication source and final upload | AUTHOR ACTION REQUIRED | Confirm journal treatment of acquired historical UTF-8 sources alongside the ASCII attachment. Check portal attachment roles, the 50 MB file limit, metadata, and publication identifiers and links. |
| Comparable software and practical usefulness | EXTERNAL VALIDATION REQUIRED | [Documented comparator review](../../../research/phase_29/jss/COMPARISON.md) scopes the synthetic benchmark. Independent reproduction and practical-use assessment remain open. |
| Full author block and declarations | AUTHOR ACTION REQUIRED | Complete [author actions](FINAL_AUTHOR_ACTIONS.md), then review the author-block page and sign off on the draft cover letter. |

The compile check establishes a reviewable PDF. It does not establish portal acceptance, editorial fit or final compliance.
