# Reviewer guide

1. Verify SHA256SUMS from this directory. Inspect the frozen protocol and configuration before comparing results.
2. Recreate the sufficient counts and output from a clean environment. Run the independent verifier without importing the production package.
3. Check the equal charged budget and the number of latent units. Confirm that the planner minimizes a proxy and has no access to outcomes.
4. Check the difference between the identification width floor and sampling uncertainty. Reconstruct the small-omission contrast and both bad-evidence counterexamples.
5. Challenge the omitted-mass and hidden-support evidence required in an actual target. A hash verifies bytes, without verifying scientific truth.
6. Record environment, hashes, commands, tolerances, conflicts, discrepancies and whether an external comparison is feasible.

Report defects with the exact command and failing checksum or result field. Preserve the old artifact and use a new version for corrections. A research citation should identify Soyeb Mohammad, GENEVRA, the research-branch commit and protocol version. No DOI or external endorsement is claimed. The project code is MIT licensed. The benchmark contains generated aggregate synthetic counts and no personal or laboratory data.
