# Design and architecture

The existing package separates organism controllers and lifetime/evolution logic from research metrics, experiment runners and evidence tools. Earlier branches of the research used paired controllers, founder/ensemble/panel decomposition, reference labels, fixed and sequential intervals, rare-event stratification, calibrated anchors and independent audit gates. The public extension adds a typed analysis module beside existing analysis modules and an experiment beside the existing runners. There is no new simulation engine or dependency.

The module provides a closed probability envelope, fixed-look binomial bands, cost-constrained two-stratum allocation and an explicit score decision. Configuration, acquisition, evidence ledger and synthetic truth scoring are separated in the experiment. Raw records contain latent denominators, paid row multipliers, shared-prefix counts and seeds. The runner binds these to frozen inputs, source hashes and environment versions. It rejects altered cells and existing result paths. A verified raw file can be reused after analysis interruption. If acquisition itself is interrupted and leaves an incomplete file, preserve it and use a fresh destination.

The historical audit identifies several methods that overlap in rate calculation, Hoeffding bounds and replay machinery. They remain frozen because Phase 13–18 bundles bind source. The extension uses likelihood-ratio inversion and a minimal standalone pipeline, so public checkout reproduction does not depend on unpublished working-tree code. Key limitations remain unqualified biological reference labels, unestablished target populations, external frame coverage, incomplete cost evidence and unverifiable dependence outside designed duplicates. A general dependence model or adaptive stopping would require separate justification.
