# Research gap and direction selection

**Question.** At which externally justified missing-mass and hidden-tail limits can a fixed-cost GENEVRA anchor certificate retain useful precision, and does optimizing a distribution-free width proxy help when actual information comes disproportionately from a rare-event stratum?

This is an unresolved engineering and empirical question for this assay and budget. The literature already resolves the generic non-identification question and supplies bounded selection, survey designs and robust prediction approaches. The project does not claim that the general problem is new.

| Direction | Decision and reason |
|---|---|
| Detect shared blindness from the same streams | Reject. Observationally equivalent worlds provide no detection signal. |
| Fuse multiple reference frames | Defer. Positive union coverage, overlap linkage and a real frame are missing. |
| Model general clustering | Defer. The frozen records support known duplicates and independent latent units. More general dependence is unidentifiable. |
| Adaptive sampling and abstention | Defer adaptive acquisition. A time-uniform guarantee controls repeated looks under a valid observation law, not coverage omissions. |
| Quantify incomplete information and budgeted precision | Implement. An independently supported mass bound gives an explicit width floor and a defensible failure control. A costed allocation ablation can distinguish theoretical worst-case width from actual usable precision. |

The most informative older finding is that Phase 18 shared blindness yielded zero mean coverage without false threshold calls. Certification, threshold resolution and interval coverage must remain separate. Phase 19 extension tests an externally bounded remedy and explicitly includes invalid bounds. No empirical source currently establishes those bounds for GENEVRA.
