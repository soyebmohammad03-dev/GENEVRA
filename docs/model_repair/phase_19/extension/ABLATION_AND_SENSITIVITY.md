# Ablation, dependence and sensitivity

- **Allocation.** At equal cost the planner directed 77.4% of the charged budget into the high-weight low-event stratum. The Bernoulli probability in the high-event stratum is .0382 versus .0002 in the other. A worst-case width proxy ignores this heterogeneity. It moved resources away from the rare-event stratum whose information mattered for realized KL width. The negative primary result is preserved. No post-hoc variance-aware allocation was fitted.
- **External hidden-tail restriction.** For the valid tight cap at 32,768, the planned envelope produced 423 covered precise intervals and 95 correct certificates. Replacing the bound by the full [0,1] range yielded zero precise intervals or certificates and median width rose from .573 to 1.721. This quantifies the value of *valid* auxiliary evidence.
- **Invalid hidden support.** The same tight restriction under the planted violation produced zero coverage and 101 false certificates with the plan. Removing that restriction restored 512/512 coverage and no certificates. It traded away precision.
- **Invalid missing-mass cap.** Removing the hidden-tail assumption alone did not help. Both envelopes had zero coverage, and equal spend issued 53 false certificates. A valid mass bound is a separate assumption. More samples from the same frame cannot validate it.
- **Duplicates.** Eight charged copies represent one IID latent unit. With equal spend at 32,768, the two independent denominators drop to 2,048 and 1,024. All runs still covered, but none met .60 width. These results do not quantify other intracluster dependence structures.
- **Threshold.** All envelope runs abstained in the high-budget near-threshold case despite meeting the width criterion. A narrow interval and a useful threshold call are different endpoints.
