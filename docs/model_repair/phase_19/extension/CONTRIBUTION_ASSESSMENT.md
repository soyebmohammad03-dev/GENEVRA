# Contribution assessment

The extension contributes a typed, reusable coverage-envelope calculation, exact costed search for a two-stratum planning proxy, explicit separation of anchor certification and threshold resolution, and a verified adverse-control benchmark. It connects a gap in the GENEVRA workflow to a testable intervention. The mathematical machinery is established partial identification and concentration. The project-specific contribution is making the external assumptions and resulting precision floor executable, then testing whether a worst-case planning objective delivers useful precision at the same budget.
