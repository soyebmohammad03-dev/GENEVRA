## Multiple-comparisons note (corrected 2026-09-13)

A confirmatory FDR family now exists: `research_evidence/statistics/rq_family_fdr.json`, built with `genevra.campaign.multiple_comparison.build_multiple_comparison_registry` (which wraps `genevra.discovery.multiple_testing.benjamini_hochberg`) over the two tests in this package that are genuinely confirmatory hypothesis tests with a predeclared primary metric: RQ1/RQ6's `case_a_reproduction` permutation test (raw p=0.8171) and RQ4b's corrected ecology comparison (raw p=0.7313). Both remain non-significant after BH correction (adjusted p=0.8171 for both) — this changes no conclusion, since neither survived even before correction. The original CONFOUNDED RQ4 result is deliberately excluded from this family (see the file's own `family_membership_rationale` field): including a confounded result's p-value in a correction family would misleadingly imply it remains a candidate finding once "properly" corrected. RQ2 (a plain correlation, no formal test), RQ3 (a sign-agreement rate, not a p-value), RQ5/RQ8 (descriptive/insufficient-data), and RQ7 (a 3-point exploratory sweep) remain outside any correction family, correctly, since Phase 17.7 requires FDR only be applied to genuinely confirmatory tests, not exploratory or descriptive analyses.

## RQ4 audit finding (see `docs/final_research_status.md` for full detail)

`experiments/exp1_isolated_vs_shared.py`'s own docstring states: *"This is an infrastructure-validation experiment... One run at one configuration establishes nothing about whether ecological interaction generally increases or decreases diversity."* The isolated condition uses `EvolutionEngine` + `GridWorld` (discrete non-overlapping generations, tournament selection, `channels=2`, i.e. a 2-plane sensory input and a smaller network `input_size`), while the shared condition uses `ContinuousEvolutionEngine` + `SharedGridWorld` (continuous overlapping generations, birth/death reproduction, `channels=3`). These are two different engines with different selection dynamics, different generation structure, and literally different-sized neural network inputs — not a single-variable ecological manipulation. The audit reclassified this from `SUPPORTED` to `CONFOUNDED`; the underlying statistic (p=0.0005, d=2.77) is real and reproducible but cannot be attributed to ecological sharing specifically. `research_evidence/tables/rq4_historical_vs_corrected.md` preserves both results side by side.

## RQ4b: the corrected same-engine experiment (targeted correction, 2026-09-13)

`experiments/exp_ecology_corrected.py` holds `ContinuousEvolutionEngine`+`SharedGridWorld`, architecture, organism config, and every other setting fixed across both conditions, varying only `resource_a_density` (0.30 vs. 0.05). Run at n=24 seeds per condition (exceeding the pre-registered 20-seed minimum) with a pre-analysis plan frozen to disk before execution. Result: **NOT_SUPPORTED** — no detectable effect (p=0.7313, d=-0.10), and per-seed replication analysis shows an exact 50/50 sign split (12/24 reversals), meaning this is a genuine null, not a real effect masked by an underpowered test.
